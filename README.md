# Comms desktop app

Installers for Comms on Windows, macOS and Linux. The newest version is always on the [latest release](https://github.com/linodashmedia/comms-downloads/releases/latest):

| Computer | Download |
|---|---|
| Windows 10 or 11 | [Comms-Windows-x64-setup.exe](https://github.com/linodashmedia/comms-downloads/releases/latest/download/Comms-Windows-x64-setup.exe) (or the `.msi` for managed installs) |
| macOS 11+ (Apple silicon and Intel) | [Comms-macOS-universal.dmg](https://github.com/linodashmedia/comms-downloads/releases/latest/download/Comms-macOS-universal.dmg) |
| Linux | [Comms-Linux-x86_64.AppImage](https://github.com/linodashmedia/comms-downloads/releases/latest/download/Comms-Linux-x86_64.AppImage), or [Comms-Linux-amd64.deb](https://github.com/linodashmedia/comms-downloads/releases/latest/download/Comms-Linux-amd64.deb) for Debian and Ubuntu |

After installing, sign in with your Comms email and password. `SHA256SUMS.txt` on each release lets you check a download.

This repository only holds release files; it is published automatically.
